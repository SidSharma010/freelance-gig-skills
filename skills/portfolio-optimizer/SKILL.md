# Portfolio Optimizer

Most freelance profiles read like a resume: a list of skills and past jobs.
Clients don't hire a list — they hire someone who clearly solves their
specific problem. This skill rewrites the profile to lead with outcomes.

## When to use

- User pastes their profile text (Upwork overview, Fiverr "About" section,
  Freelancer.com bio) and wants it reviewed or rewritten
- User says their profile "isn't converting", "isn't getting views", or asks
  to "make my profile better"

## Input

- Current profile text, or a description of what's there
- Platform (Upwork / Fiverr / Freelancer.com / other)
- Niche/specialty and who they want to attract (e.g. "small e-commerce
  brands needing Shopify fixes" beats "web development")
- Optional: 2-3 real past projects or results to draw specifics from

## Steps

1. **Identify the actual niche.** A profile that tries to serve everyone
   converts worse than one that names a specific client type and problem.
   If the user's profile is generic, ask what they most want to be hired for.
2. **Score the current profile** against the checklist below.
3. **Rewrite the opening line/headline** — this is what shows in search
   results and gets one sentence to earn a click. State the outcome you
   deliver, not your job title.
4. **Rewrite the body** using real specifics the user provides (past
   projects, tools, a rough result) — never invented numbers.
5. **Flag anything that needs the user's input** (a metric, a client type,
   a tool version) rather than filling it with a plausible-sounding guess.

## Platform-specific checklist

### Upwork overview
- First sentence must work as a standalone hook — it's what shows before
  "more".
- Lead with the client's problem, then how you solve it, then (briefly) who
  you are.
- Name specific tools/technologies — Upwork's search matches on these.
- Avoid "I am a hardworking, detail-oriented professional" — every profile
  says this; it filters nothing.

### Fiverr seller profile + gig titles
- Gig title format matters more than the bio: "I will [specific outcome] for
  [specific client type]" beats a vague service name.
- Seller "About" section is secondary to the gig gallery — prioritize
  rewriting gig titles/descriptions over the bio if only one can be fixed.
- Include the exact deliverable and turnaround in the gig description, not
  just the bio.

### Freelancer.com
- Profile tagline should state a specialty, not "Freelancer.com professional
  offering top service".
- Portfolio samples matter more here — the written bio is skimmed less than
  on Upwork.

### Personal portfolio site / other
- Above-the-fold: who you help + what outcome, in one sentence, before any
  scroll.
- Case studies beat skill lists — one real project with a before/after beats
  ten bullet points of tools.

## Hard rules

- Never invent a client name, result number, or years-of-experience figure.
  Ask for it, or write around it honestly ("results vary by project scope"
  is worse than just asking the user for one real example).
- First person, not third person ("I help..." not "Satish is a...").
- No "passionate", "hardworking", "detail-oriented", "results-driven" — these
  appear on effectively every competing profile and signal nothing.
- Keep platform-appropriate length — a Fiverr gig title has a hard character
  cap; don't write copy that needs trimming later.

## Output shape

1. **Score**: what's working, what isn't, ranked by impact
2. **Before → After** for the headline/opening line
3. **Before → After** for the body/bio
4. Any gaps flagged — real details the rewrite needs that weren't provided
